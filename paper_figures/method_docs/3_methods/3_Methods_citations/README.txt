3_Methods -- papers to cite from (sections 3.1 ... 3.4)
======================================================================

Drop the PDFs you want cited anywhere in the method here.  Anything in
this folder is read, not written to: the manuscript text is built from
paper_figures/programs/make_method_docs.py, so a citation is applied
there, not in the .docx.

Naming helps but is not required.  Something like

  2018_Zwolak_autotuning.pdf
  2023_Ziegler_ray_based_tuning.pdf

is enough to point at one from the comment sheet of the subsection it
belongs to -- e.g. in 3_2_Ray_based_measurement.txt:

  -cite Ziegler ray-based tuning in S1 P2

The PDFs are gitignored.  They are the publishers', and this repo goes
public with the paper; only this note is committed.
